# 🕸️ SPINDLE

> **SPINDLE - визуальный инструмент для создания, организации и исследования связанных данных.**

SPINDLE позволяет представлять информацию в виде интерактивной сети из узлов и связей. К каждому объекту можно добавлять дополнительную информацию, изображения и файлы, а содержимое проекта - фильтровать, экспортировать и импортировать.

## ✨ Возможности

### 🧩 Узлы

Создавайте информационные узлы и назначайте им типы.

Каждый узел может содержать:

* название и информацию;
* определённый тип;
* до **3 изображений**;
* прикреплённые файлы;
* связи с другими узлами.

---

### 🔗 Связи

Соединяйте узлы между собой и создавайте визуальную структуру проекта.

Это позволяет видеть не только отдельные объекты, но и отношения между ними.

### 🖼️ Изображения

К каждому узлу можно добавить до **трёх изображений** и просматривать их непосредственно внутри проекта.

Изображения могут использоваться для:

* фотографий персонажей;
* мест;
* предметов;
* документов;
* референсов;
* других визуальных материалов.

## 🤖 SPINDLE Copilot

**SPINDLE Copilot** — экспериментальная интеллектуальная функция SPINDLE, предназначенная для помощи пользователю в работе с проектом.

На текущем этапе Copilot **не является полноценным ИИ-ассистентом**. Его возможности пока ограничены, однако в дальнейшем планируется значительно расширить его функциональность и превратить его в полноценный интеллектуальный инструмент, способный глубже взаимодействовать с данными проекта.

### 🔎 Поиск связанных узлов

Единственная доступная на данный момент функция Copilot — **поиск связанных узлов**.

Copilot анализирует существующие связи внутри проекта и помогает определить, какие узлы связаны с выбранным объектом. Это позволяет быстрее ориентироваться в больших сетях и находить нужные взаимосвязи без ручного просмотра всей структуры.

> **Текущая версия:** экспериментальная функция поиска связанных узлов.
> **В будущем:** расширенный AI-инструмент для работы с проектами и их содержимым.

# 🎯 Для чего нужен SPINDLE?

SPINDLE подходит для любых задач, где большое количество информации связано между собой.

### 🕵️ Исследования

Люди, события, места, документы и взаимосвязи между ними.

### 📖 Создание миров

Персонажи, фракции, локации, события, предметы и история мира.

### 🎮 Разработка игр

NPC, квесты, персонажи, локации, предметы и сюжетные связи.

### 🧠 Организация информации

Создание визуальных карт вместо обычных списков и разрозненных заметок.

# 🖥️ Концепция

Основная идея SPINDLE проста:

```text
       ┌─────────┐
       │ PERSON  │
       └────┬────┘
            │
       ┌────┴────┐
       ↓         ↓
    EVENT      PLACE
       │
       ↓
   DOCUMENT
```

**Узлы содержат информацию, а связи показывают отношения между ней.**
